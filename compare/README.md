# 二重実装の照合

受取帳は同じ解析ロジックを2つ持っている。

- `index.html` — ブラウザ版（JavaScript）
- `cli/` — CLI 版（Python）

同じメールを両方に流して同じ結果が出るかを、1件ずつ機械的に突き合わせる。

## なぜ目視レビューでは足りないのか

2つの実装を並べて読んでも差は見つからない。どちらも意図どおりに見えるし、
動かせば両方それらしい出力を返すので、食い違いに気づく手がかりが無い。

この領域の欠陥は例外を投げない。文字コードの復号漏れも、実体参照の未処理も、
MIME 分割語の空白の扱いも、**エラーではなく「もっともらしい別の値」**として出てくる。
だから正解と突き合わせる装置がないと、そもそも発見できない。

## 必要なもの

- Python 3.10 以上（標準ライブラリのみ）
- Chrome / Chromium / Edge のいずれか1つ（ブラウザ実装を本物の環境で動かすため）

動作確認は macOS で行っています。Windows では試していません。

## 使い方

```bash
python3 compare/make_fixtures.py   # .eml を生成（初回のみ）
python3 compare/compare.py         # 突き合わせ
```

`.eml` はリポジトリに入っていません。実データを誤って混ぜないよう
`.gitignore` で `*.eml` を丸ごと弾いているためで、フィクスチャも例外にしていません。
生成せずに走らせた場合は、差分ゼロで通らずにその場で止まります。

差分があれば終了コード 1。一度きりの検証ではなく、解析まわりを触るたびに回す。

ヘッドレスブラウザが動かない環境（サンドボックス下など）では、
ページを書き出して普通のブラウザで開く:

```bash
python3 compare/run_js.py --emit-page /tmp/harness.html
```

開いた画面に出る文字列をファイルに保存して渡せば、同じ照合ができる。

```bash
python3 compare/compare.py --js /tmp/result.txt
```

`--js` は JSON でも base64 でも受ける。`run_js.py` が起動に失敗した場合も、
この手順を含むメッセージを出して終わる。

## 構成

| ファイル | 役割 |
|---|---|
| `make_fixtures.py` | 壊れ方を狙った `.eml` を生成する |
| `run_py.py` | Python 実装に流して JSON を出す |
| `run_js.py` | ブラウザ実装に流して JSON を出す |
| `compare.py` | 2つを突き合わせて差分を出す |

## 設計上の判断

### 実データを使わない

実際の領収書メールには取引IDも金額も入っているので、リポジトリには置けない。
代わりに、**過去に壊れた箇所を狙って踏ませる入力**を生成する。
狙いはメールらしさではなく、壊れ方の再現である。

`.eml` を手書きせず生成するのは、ISO-2022-JP のエスケープ列や base64 が
エディタで壊れることと、どのバイトが何を狙っているのかを
生成コードにしか書けないため。

### ブラウザ実装は本物のブラウザで動かす

解析コードは `DOMParser`（実体参照）と `TextDecoder`（文字コード）に依存している。
Node には `DOMParser` が無いので代替を差し込むことになるが、それをやると
**照合しているのは本物の経路ではなく差し込んだ実装のほう**になる。
壊れ方は差し込んだ場所に出るので、装置として意味がなくなる。

なので手元の Chrome をヘッドレスで起動して実行する。追加インストールは無い。

ここで1つ踏んだ。`--dump-dom` は DOM を標準出力に書いたあとも、**Chrome が終了しない**
ことがある（自動更新のプロセスが上がるなど）。プロセスの終了を待つ実装にすると、
結果はとっくに手元にあるのに必ずタイムアウトする。
出力の終わりは終了コードではなく `</html>` で判定して、読めたら落とす。

### コードは書き写さず切り出す

`index.html` の該当部分をコピーすると3つ目の実装が生まれ、照合の意味が消える。
`=== 照合対象ここから ===` から `=== 照合対象ここまで ===` までを実行時に切り出して使う。
印を動かすか、DOM に触る処理をこの範囲に入れると、ここで落ちる。

## 見ていないもの

- **重複排除** — `Message-ID` による除外はブラウザ版の集計側にあり、この照合には含めていない
- **集計・出力** — CSV の桁揃えや為替換算は対象外。ここで見るのは1通を1レコードにするまで
